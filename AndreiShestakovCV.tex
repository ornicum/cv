Senior backend engineer with about 20 years of commercial software development experience, currently focused on Rust, Python, and high-performance backend systems. My background includes distributed systems, data processing, time-series processing, and simulation.

I work with Rust and Python together, choosing the right technology for each part of a system. Python is a strong choice for application logic and data processing, while Rust is useful for performance-critical parts where speed, resource usage, and predictable performance matter. I also have experience integrating Rust components into Python applications, including replacing slow Python components with Rust modules instead of rewriting the whole system.

I care about the quality of the whole system, not just the code I write. I try to understand how a system works as a whole, where problems really come from, and what can be improved without adding unnecessary complexity. For me performance, reliability, maintainability, and development speed are all part of building a good product.

I want my work to make the product better — faster, more reliable, easier to maintain, or easier to develop further. I take responsibility for the result, not just for implementing the task I was given.

Currently, I’m building a distributed platform for real-time processing, simulation, and analysis of time-series data, with a focus on modular architecture, in-memory processing, predictable execution, and performance optimization.
